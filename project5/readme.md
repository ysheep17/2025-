
1. **椭圆曲线参数与基础运算**

   * `p, a, b, n, Gx, Gy` 是 SM2 椭圆曲线的标准参数（基于 GB/T 32918.1–2016）。
   * `mod_inverse`：计算模逆（扩展欧几里得算法）。
   * `point_add` / `point_double` / `scalar_mult`：椭圆曲线上的点加、点倍运算（核心 ECC 算法）。

2. **密钥对生成**

   * `generate_keypair()`：随机生成私钥 `d`（1 ≤ d ≤ n-1），计算公钥 P = d·G。

3. **SM3 哈希函数**

   * 代码里内嵌了一个 SM3 实现（用于签名的 `Z` 值计算和消息摘要）。
   * 可以直接调用 Python 绑定的国密 SM3 库
4. **签名与验签**

   * `sm2_sign(d, msg)`：实现标准 SM2 签名（生成随机数 k，计算 r, s）。
   * `sm2_verify(P, msg, signature)`：实现标准 SM2 验签（计算 t，验证 r' == r）。

5. **误用 PoC（b 项）**

   * 通过固定或重复 k 来演示密钥泄露漏洞。
   * 如果两次签名使用相同 k，则私钥 d 可被直接推导。

6. **伪造中本聪签名（c 项）**

   * 用任意名字（如 "Satoshi Nakamoto"）构造 SM2 签名，并用验证函数证明签名是合法的。
